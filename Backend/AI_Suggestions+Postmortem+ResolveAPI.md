# IntelOps – AI, Resolution & Postmortem API Documentation

## 1. Overview

This layer defines the intelligent incident lifecycle:

- **AI-assisted analysis** (collaborative)
- **Incident resolution** (controlled)
- **Postmortem finalization** (authoritative)

## 2. Core Principles

- **AI → Suggests**
- **Team → Collaborates**
- **TeamLead → Decides**
- **System → Enforces**

## 3. Permission Matrix

### 3.1 AI Suggestions
| Action | Allowed |
|---------|---------|
| Generate | TeamLead + Responders |
| Update | TeamLead + Responders |
| View | TeamLead + Responders + Admin |

### 3.2 Incident Resolution
| Action | Allowed |
|---------|---------|
| Resolve | TeamLead only |

### 3.3 Postmortem
| Action | Allowed |
|---------|---------|
| Initial (AI) | AI API |
| Final Update | TeamLead only |
| View | TeamLead + Responders + Admin |

## 4. AI Analysis API

### 4.1 Endpoint
`POST /api/ai/analyze`

### 4.2 Authorization
- ✔ AssignedLead OR Responders 
- ❌ Others denied 
# 4.3 Request
{
  "incidentId": "string"
}

## 4.4 Validation Rules
- ✔ Incident exists
- ✔ User is assignedLead or responder
- ✔ Incident NOT resolved
- ✔ Timeline has ≥ 1 event

## 4.5 Processing Flow
1. Fetch incident
2. Fetch timeline (sorted)
3. Build context
4. Generate AI output
5. Update aiSuggestions
6. Conditionally update postmortem (if empty)
7. Create timeline entry
8. Notify users
9. Emit socket events

## 4.6 AI Output

  "nextAction": "Restart service",
  "timelineSummary": "14:00 - Incident reported\n14:20 - Investigation started",

------------

```

```

* * * * *

5.2 Authorization
-----------------

```
✔ Only TeamLead (assignedLead)❌ Others denied
```

* * * * *

5.3 Request
-----------

```
{}
```

(No body required)

* * * * *

5.4 Validation Rules
--------------------

```
✔ Incident exists✔ User is assignedLead✔ Incident NOT already resolved✔ At least 1 responder assigned

5.5 Processing Flow
-------------------

```
1\. Fetch incident2\. Validate ownership (TeamLead)3\. Validate not resolved4\. Validate responders exist5\. Update status → resolved6\. Set resolvedBy7\. Set resolvedAt8\. Save9\. Create timeline entry10\. Notify users11\. Emit socket events

8\. Full Lifecycle Flow
=======================

```
Bugger → Create Incident        ↓System → Assign Group + Lead        ↓TeamLead → Assign Responders        ↓Team → Add Timeline Updates        ↓TeamLead/Responders → Run AI        ↓System → Store AI Suggestions        ↓TeamLead → Resolve Incident        ↓TeamLead → Finalize Postmortem        ↓System → Notify + Socket Events
```
